Hello World — Instructions

What’s included:
- index.html — the page students can open
- styles.css — starter styles
- assets/image.jpg — placeholder image for practice

How to run:
- Open index.html in a browser, or run a simple local server (optional):
  - Python: python -m http.server 8000
  - Then open http://localhost:8000 in your browser

Replace the image:
- Replace assets/image.jpg with your own image (keep the same filename), or update the <img> src in index.html.

Notes for instructors:
- This project is intentionally minimal. Ask students to add meta tags and a favicon as an extension.
